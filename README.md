# Oreo Cat Game

This game is about playing as a cat named Oreo. Avoid being chaotic - or not.

## Features

- Players can choose options that shape how their mom reacts to them.
- Depending on what you choose, you get an ending corresponding to what you did.
- The player can save whenever they want between choices.
- Chaos points can be earned by being mischievous. The more chaos points you earn, the more suspicious your mother becomes of you.

## Running the Game

Type `save` to save, and in the beginning, choose 2 to load a game. The game is very simple.

## Learning Context

I made this when I was around 12 while learning Python. It was my first ever project I could proudly call a game. I had decided to make a game based off my cat, Oreo. And I built the rest from there.
